# gta6kit

GTA VI portal in 13 languages: countdown, price, guides, map and a fact base.

**Website: [https://gta6kit.com](https://gta6kit.com)**

## Example

`countdown.js` counts down to any future date — the same widget idea the
portal uses for the release timer:

```bash
node countdown.js "2026-12-31T00:00:00Z"
```

The full portal lives at [https://gta6kit.com](https://gta6kit.com).
